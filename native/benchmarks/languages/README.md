# Shared numerical fixtures

`kernels.k`, `gpu.k`, `Driver.cpp` and `GpuDriver.cpp` support the
[fair numerical-library runner](../fair/README.md) and GPU correctness tests.
The earlier loop-versus-native-primitive language ranking was retired because
it compared different implementation strategies. Its scripts and reports remain
in the [research archive](../../../benchmarks/research-archive.json).
